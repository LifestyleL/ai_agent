根据《虚拟智能体项目架构方案》第二阶段要求，已将后端 Python 代码从 `my-react-app/my_agent/` 目录迁移至标准化的 `backend/` 目录结构。本次迁移严格遵守"只移动，不重构业务逻辑"的铁律，保持了系统的可运行性。

## 1. 文件夹移动记录

8. **backend/core/llm/llm_collaborator.py**

### 导入修复原则
1. **绝对导入**：跨目录的导入使用绝对路径（如 `from services.live2d import ...`）
2. **相对导入**：同一目录下的模块使用相对导入（如 `from .animator import ...`）
3. **延迟导入**：避免循环导入，在函数内部需要时再导入
